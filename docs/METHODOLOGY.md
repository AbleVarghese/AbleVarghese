# Portfolio metrics: methodology

Every number on this profile is computed, not claimed. This document and `forensics.py` let anyone
reproduce them against the underlying repositories (private repos verifiable on request).

The table below is generated by `scripts/sync_figures.py` from the same audit output the charts
read, so no figure here can drift out of step with the profile. Do not hand-edit it.

<!-- method start -->
| Metric | Method |
|---|---|
| Commits (16,081) | `git log --all --format=%at\|%ae\|%an` across 27 original (non-fork) repositories, December 2024 to October 2026 |
| Active days (335) | Distinct calendar dates among all commit timestamps |
| Hours (~3,117 to ~5,002) | Session clustering (the git-hours algorithm): commits 120 min apart or less form a session; the range is the sum of intra-session gaps plus a per-session start adjustment of 30 min (low) or 120 min (high). An estimate of orchestration wall-clock, labeled as such |
| Lines of code (2.04M) | `git ls-files` on the 22 locally-present repos, code extensions only, excluding dependencies, lockfiles, build output and vendored code. Includes SQL, config and styles, because it is *tracked, authored* code rather than business logic alone |
| Test files (2,700) | Files matching test and spec naming conventions among counted code files |
| Docs (4,003 files / 871K lines) | Markdown census, same exclusions |
| Night and evening share (48%) | Commits with author-hour at or after 17:00, or before 02:00 |
| COCOMO ~597 person-years | COCOMO-81 organic model, PM = 2.4 x KLOC^1.05 on measured LOC. A model of *conventional hand-written* effort, cited precisely because agentic engineering breaks its assumptions |

**Honest boundaries:** every figure is *committed repository-history delivery* (`git log --all` on the
manifest-listed repos in `docs/audit-manifest.json`): it counts committed history, including
agent/bot commits made under the owner's direction, and it excludes all uncommitted work
(19 repos currently hold uncommitted changes, excluded, never counted as zero work).
A date with no qualifying commit means no counted commit landed that day, never that no work happened.
Hour figures are estimates from commit patterns, not timesheets. LOC is
measured on the 22 repos present locally; 5 more are counted for commits only. Work predating
December 2024, such as an earlier fintech prototype, sits outside these histories and is excluded.

**Pre-2023 career record:** the 5,000+ commits / 20+ projects / 1 to 37-member teams figure for
2014 to 2023 is the owner's stated career record, consistent with the LinkedIn history, and is not
part of the git-measured numbers above. Those repositories are corporate, private and contractually
confidential, so they cannot be published or independently audited here.

**Lines delivered per day (6.46M added):** `git log --all --numstat` across the locally audited
repos, additions summed per author-date, with dependency, lockfile and build paths excluded.
Additions exceed final LOC (2.04M) because code gets rewritten; both numbers are stated. Commit
dates lag the work they contain: multi-day efforts often land in one commit, so the 332 recorded
active delivery days are a lower bound on true working days, and single-day spikes are usually
batch landings. The daily chart uses a square-root scale, stated on the chart, so median days stay
visible next to the 590K peak.

## Revision, 2026-08-17 (v2 methodology)

Numbers were re-derived across **21 repositories** (up from 15) after three of the previously
commits-only repos became locally auditable and two new projects landed. The counting rules were
also tightened, so the change reflects both new work and a stricter method:

| Rule | v1 | v2 |
|---|---|---|
| Generated tool/agent state (`.claude/persistence/`, `snapshot-*.json`, `recovery-*.json`, `*.wal`, work-history dumps) | counted | **excluded** |
| Vendored/archived duplicate trees inside a repo | counted | **excluded** |
| Identical file contents appearing at several paths | counted once per path | **counted once**, deduplicated by git blob hash |
| Daily "lines delivered" | every changed file | **authored extensions only** (code + Markdown) |

The v2 rules were adopted after an audit found a monorepo contributing 150M apparent added lines,
almost all of it committed agent-state JSON. That figure was never published; it was caught by
sanity-checking the per-repo table before publication.

Excluded by choice: the profile repository and portfolio site themselves, and two third-party
checkouts. Recovery duplicates of an existing repo are excluded to avoid double counting.

## Revision, 2026-08-20 (product claims re-verified; figures made derived)

Two changes, one mechanical and one about honesty.

**Every published figure is now generated, not typed.** The v2 refresh left stale numbers inside
SVG alt text and inside the banner and architecture diagram, because those strings were hand-written
while the charts read the audit JSON. Two scripts now close that gap: `scripts/gen_assets.py` builds
all twelve SVGs from `docs/forensics.json`, and `scripts/sync_figures.py` rewrites the figures and
alt text in the README, this file, and the portfolio site from the same source. A refresh is three
commands, and a number cannot disagree with itself across surfaces.

**Product claims were re-counted against their own repositories, not carried forward.** Four moved:

| Claim | Was | Now | Why |
|---|---|---|---|
| Scrapos scrapers | 64 | **73** | direct count of scraper implementations |
| Flowen test methods | 2,838 | **3,349** | direct count of test declarations |
| ArgusTest "78% noise reduction" | published | **removed** | the product's own open audit item lists it as unsubstantiated |
| Dwellium "294-table schema" | published | **removed** | not derivable from the repository: the schema is unversioned in a remote database, so it fails the standard this page sets |

The last two are the point. A portfolio that says every number is checkable has to drop the numbers
that are not, including the flattering ones. Both were replaced with facts the audit script produces.
